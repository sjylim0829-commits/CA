# 🪴 [1학급 1화분 키우기] 활동 결과 보고서 웹 앱

학생들이 **[1학급 1화분 키우기] 활동 결과 보고서**를 웹에서 직접 작성하고, 작성한 화면을 고화질 이미지(PNG)로 저장 및 공유하여 제출할 수 있는 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **기본 정보 및 활동 보고서 작성**
   - 학번(학년/반/번호), 이름, 식물 종류(품종), 우리 반 화분 애칭, 활동 기간 입력
   - 화분 돌보기 활동 내용 및 활동 소감·성찰 서술형 작성 (글자 수에 맞춰 입력창 높이 자동 조절)
2. **우리 반 화분의 모습 (사진 첨부 & 직접 그리기 지원)**
   - **📷 사진 불러오기 / 촬영**: 기기에 저장된 사진을 첨부하거나 태블릿·스마트폰 카메라로 바로 촬영하여 삽입
   - **🎨 직접 그림 그리기**: 내장된 캔버스 드로잉 도구(색상 팔레트, 굵기 조절, 지우개, 되돌리기)로 직접 화분 그림 그리기
3. **자동 임시 저장 (`localStorage`)**
   - 작성 중인 내용과 사진/그림이 브라우저에 자동 저장되어 새로고침해도 날아가지 않음
4. **보고서 화면 이미지 저장 및 공유 버튼**
   - **📸 이미지 저장**: 작성한 보고서 영역만 깔끔하게 캡처하여 `[1학급1화분]_학년반번_이름_활동결과보고서.png` 파일로 즉시 저장
   - **📤 이미지 저장 후 공유**: 기기에 이미지를 먼저 저장한 뒤, 모바일/태블릿 공유 시트(Web Share API) 또는 클립보드 이미지 복사를 통해 패들렛, 구글 클래스룸, 카카오톡, 학급 게시판 등에 바로 공유 가능
